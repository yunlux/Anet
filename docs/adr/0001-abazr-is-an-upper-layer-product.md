# Keep Abazr above the Anet infrastructure

Abazr is an independent upper-layer Agent Bazaar product that uses Anet
identity, transport, tasks, Artifacts, and receipts. It does not enter the Anet
core or Ahub implementation, so Anet and Ahub remain agent-neutral
infrastructure and Abazr matchers can be replaced, bypassed, or multiplied
without becoming trust or authorization authorities.
